## Операторы, формирование, списки

### Операторы и сечения

**операторы** - комбинация из специальных значков, можно сделать бесконечное колво, бинарные и инфиксные(кроме минуса)  

```hs
a *+* b = a ^ 2 + b ^ 2
(**+**) a b = ...
x `plusminus` y = (x + y, x - y)
```

```hs
1 *+* + 3
1 *+* 3 *+* 4
-- в каком порядке,
```

`infixl`, `infixr`, `infix` - расставить **приоритет** и ассоциативность  

```hs
infixl 6 *+*, **+**
infixr 5, `plusminus`
```

приоритет стандартныйх операторов - *см през*  

`$` - оператор применения, `f $ x = f x`, а зачем? потому что применеия это 10 приоритет и левая асс, а `infixr 0 $`

```hs
f (g x) = f $ gx
f (g x(h y)) = f $ g x $ h y
f $ gx (h y) --оптимально
```

**Сечения** -

```hs
(2 *+*) = (*+*) 2 = \y -> 2 *+* y
(*+* 3) = \x => x *+* 3
```

**`(.)`**

```hs
f . g = \x -> f(g x)

(^2) . (+5) $ 1 --36
```

**`&`** - обратное от доллара  

```hs
(+12) $ (*10) $ 3
3 & (*10) & (+12)
```

**`(!!)`** - оператор доступа по индексу

### ленивость и строгость, форсирование

основание, дно, `⊥` - ошибка

```hs
bot :: Bool
bot = not bot
:t bot = ⊥
```

```hs
ignore x = 42
ignore undefined -- 42
ignore bot -- 42
-- нестрогая функция
```

для *строгих* всегда `f ⊥ = ⊥`  

`seq` - форсирование вычислений, удаляем нестрогость  

```hs
seq ⊥ b = ⊥
seq a b = b -- если a != ⊥
```

но `seq` смотрит до сгнф(не редекс на верхнем уровне)

```hs
seq (undefined, undefined) 42 -- 42
seq (\x -> undefined) 42 -- 42
seq ((+) undefined) 42 -- 42
```

**`$!`** = `f $! x = x seq f x`  

вспомним факториал с acc - там накапливается в сиу ленивости thunk - накполенная операция, оптимизатор обычно чправляется, но можно  

```hs
... - (helper $! acc * k) (k - 1)
```

### стандратные списки

списки имеют два конструктора - `[]`, `(:)`  

```hs
[] :: [a]
(:) :: a -> [a] -> [a]

infixr 5 :

[1, 2, 3] = 1:(2:(3:[])) = 1:2:3:[]

head (x:_) = x
head [] = error

tail (_:xs) = xs
tail [] = error

[] ++ ys = ys
(x:xs) ++ ys = x : xs ++ ys

take n _ | n <= 0 = []
take _ [] = []
take n (x:xs) = x : take (n - 1) xs

drop ...
drop 1 = tail

-- фукнции высших порядков

filter _ [] = []
filter p (x:xs)
    | p x = x : filter p xs
    | otherwise = filter p xs

map _ [] = []
map f (x:xs) = f x : map f xs
map ((^2) . length) $ ["aa", "bbb", "cccc"] -- [4, 9, 16]

zip [] _ = []
zip _ [] = []
zip (a:as) (b:bs) = (a, b) : zip(as, bs) -- при разных длинах мы остановимся

zip3, zip4, zip5 ...
unzip = ...

zipWith _ [] _ = []
zipWith _ _ [] = []
zipWith f (a:as) (b:bs) = f a b : zipWith f as bs

zipWith3, zipWith4 ...

numsFrom n = n : numsFrom(n + 1) -- n = 0 => 0, 1, 2, ...
squares = map (^2) (numsFrom 0) -- 0, 1, 4, 9, ...
take 10 squares -- вычисления ленивые, считаем ток 10 первых

fibs = 0 : 1 : zipWith (+) fibs (drop 1 fibs)

[1..10] -- [1, 2, 3, ..., 10]
[1, 3..17] -- [1, 3, 5, 7, .., 15, 17]
['A'..'z'] -- ABCD...Z[\\]^_`abcd...z
[1..] -- [1, 2, 3, ...]
```

#### list comprehension

```hs
digits = [0..9]
[ x^2 | x <- digits] -- [0, 1, 4, 9, 16, .. ,81]

[ [x, y] | x <- "ABC", y <- "de"] -- ["Ad", "Ae", "Bd", "Be", "Cd", "Ce"]
```

```hs
[ (x, y) | x <- [1..3], y <- [1..x] ] -- ссылаемся на прошлое значение

l = [1..19]
[ (a, b, c) | a<-l, b<-[1..a], c<-l, a^2 + b^2 == c^2 ] -- условие
-- [(4, 3, 5), (8, 6, 10), ...]

tst = [(1, 7), (2, 4), (3, 11)]
[ x + y | (x, y) <- tst ] -- сопоставление
```
