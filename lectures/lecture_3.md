## Просто типизированные лямбда исчисления

### Понятия типа

**Система типов** - нужна для того, чтобы показывать что программа в нек ситуациях себя так вести не будет  
**Тип** - синтаксические конструкции (M:A, где А,B, C,.. это типы)  

Обозначнеие a -> b является типом функции из а в b

```haskell
I: a -> b
y:a |- (Iy):a
-- контекст(слева от Т)
```

**Системы**:

1) В стиле Карри - термы без типовой теории, у каждого бесконечно много типов
2) В стиле Черча - у каждого терма один тип

### Просто типизированное лямбда исчисление

- это лямбда со стрелкой (SST, Simple Type Theory)

стрелка право ассоциативна  

M^A == M:A

к переменной можно приписать любой тип  
к апликации нужно следить за типами(M:A->B, N:A, MN:B)  
к абстракции тип определяется по аргументам(lx.M:A->B, x:A, M:B)

в абстракции мы обязаны писать тип(lx^a. x)  

### Формализм систем стрелочного типа

**предтермы** в стиле *карри* - термы(предтермы с типом превращаются в термы)  
**предтермы** в стиле *черча* - термы с аннотированными типами  

**утверждение типизации** в стиле *карри* - вид M:A, A - предикат, M - субъект  

**объявление** - типизация терма
**контекст** - это множество объявлений(большие греческие буквы)

см лемму типизации в през(аксиома + ->E + ->I)(для череча прост еще раз пишем тип в лямбде)  

### Свойства стрелочной типизации

**Лемма** об инверсии (лемма генерации):  
> можно рассказать дерево в обратном порядке

**Лемма** о типизируемости подтерма:  
> если терм имеет тип, то любой его подтерм имеет тип

еще много лемм....  

не все подтермы типизируются: пример - омега малое,а так же то, что содержит омега малое  

подставновку можно делать и с типами  
**Лемма** подстановки:  
> делаем подстановку и в контексте и в типе для карри, для черча еще + в терме

**Лемма** подстановки для терма:  
> подходящая по типу подстановка не меняет тип

**Теорема** о редукции субъекта:  
> тип терма сохраняется при бета-редукциях
